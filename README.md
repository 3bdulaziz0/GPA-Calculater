# حاسبة المعدل — GPA Calculator

حاسبة معدل جامعي عربية تعمل في المتصفح، بواجهة RTL ووضع داكن.

<https://calc-my-gpa.web.app>

## الفكرة

أضف موادك ودرجاتها وساعاتها، واحصل على المعدل الفصلي والتراكمي فورًا.
تدعم نظامي **5.00** و **4.00**، والتحويل بينهما.

## مسار كلية الحاسبات

`/FCIT` يفتح النسخة نفسها مع خطة كلية الحاسبات وتقنية المعلومات محمّلة
مسبقًا — أسماء المواد وساعاتها جاهزة، فيبقى إدخال الدرجات فقط.

<https://calc-my-gpa.web.app/FCIT>

## التشغيل محليًا

الموقع ملفات ثابتة، بلا خطوة بناء:

```bash
npx serve public
```

## النشر

```bash
firebase deploy
```

`firebase.json` يعيد توجيه `/FCIT` إلى `index.html` ليتولّى `FCIT.js` الباقي.

## البناء

HTML و CSS و JavaScript خام، مع Bootstrap 5 للواجهة و Firebase Hosting للنشر.
لا إطار عمل ولا خادم ولا قاعدة بيانات.
